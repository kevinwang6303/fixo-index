## 1. 產品定位與核心架構

VPC（Virtual Private Cloud）為使用者在 FiXo 上建立的邏輯隔離專用網路環境。使用者擁有對網路環境的完整控制權，可自訂 IP 位址範圍（CIDR）、劃分子網、配置路由器、設定安全通訊埠、指派浮動 IP 以及建立跨專案的對等互連。

```mermaid
flowchart TD
    Internet([網際網路 Public Internet]) <--> FIP[浮動 IP Floating IP]
    FIP <--> Router[VPC 路由器 Router / Gateway]
    Router <--> Subnet1[子網 A: 192.168.1.0/24\n(Web 前端)]
    Router <--> Subnet2[子網 B: 192.168.2.0/24\n(DB 後端)]
    Subnet1 <--> VM1[FiCo 虛擬機 1]
    Subnet1 <--> VM2[FiCo 虛擬機 2]
    Router -.->|對等連接 Peering| PeerRouter[對端 VPC 路由器 / 專案]
```

## 2. 核心模組與功能詳解

### 2.1 網路 (Network) 與子網 (Subnet)

#### 建立網路的兩種模式
1. **快速建立**：系統化精簡流程，僅需選擇指定的外部網路並關聯路由器，即可自動完成虛擬網路與預設子網配置。
2. **自訂建立（建立網路）**：支援完整進階設定：
   * **基本配置**：網路名稱、啟用/停用狀態、共享屬性。
   * **子網設定**：CIDR 網段定義（如 `192.168.1.0/24`）、IPv4 協定、預設閘道 IP（Gateway IP）。
   * **DHCP 服務**：可啟用/停用動態 IP 指派，並自訂 **位址分配池（Allocation Pools）** 避開保留 IP。
   * **主機路由（Host Routes）**：設定推送給虛擬機的主機層級路由資訊。

#### 主機路由 vs. 靜態路由概念對比
* **主機路由（Host Routes）**：配置於**子網**層級，藉由 DHCP 租約直接下發至該子網內的虛擬機作業系統 Routing Table 中。
* **靜態路由（Static Routes）**：配置於**路由器**層級，由 VPC 路由器依據自訂規則進行跨網段流量轉送。

#### 通訊埠管理 (Port)
* 檢視虛擬網卡所屬通訊埠之 IP 位址、MAC 位址、管理狀態、綁定設備類型。
* 支援修改通訊埠名稱與自訂狀態調整。

#### 網路刪除防護條件
* 刪除網路前，**必須確保該網路下已無任何運行中的虛擬網卡、已分配未釋放的浮動 IP 或關聯的路由器接口**，否則系統將拒絕刪除以防網路中斷。

---

### 2.2 路由器 (Router) 與閘道管理

* **閘道綁定（Gateway IP）**：將路由器連接至外部實體公網，使其具備 SNAT 存取外網或接受公網轉發之能力；支援隨時綁定與解綁閘道 IP。
* **子網接口管理（Interfaces）**：
  * **綁定接口**：將自訂內部子網串接至路由器，建立跨子網內部通訊管道。
  * **解綁接口**：切斷子網與路由器的通訊關聯。
* **靜態路由配置（Static Routes）**：
  * 用於轉發特定目標網段至自訂虛擬路由設備（如軟體防火牆或 VPN 閘道）。
  * 核心設定包含：**目的網段 CIDR**（Destination CIDR）與 **下一跳 IP**（Next Hop IP）。
* **路由器刪除條件**：需事先解綁外部公網閘道 IP 並移除所有掛載的子網接口。

---

### 2.3 浮動 IP (Floating IP / 彈性公網 IP)

* **位址池分配**：從指定的外部公網 IP 池中申請可獨立持有的公網 IP 位址。
* **彈性關聯/解關聯**：
  * 可動態綁定至特定虛擬機的私有通訊埠，或進階負載平衡器（LBS VIP）。
  * 業務維護時可隨時解關聯並重新綁定至備用主機，實現零停機容災切換。
* **釋放機制**：支援單一釋放與**批次釋放（Batch Release）**，未使用的浮動 IP 釋放後將返還公網位址池。

---

### 2.4 浮動網卡 (Floating NIC) 與進階網路特性

* **建立浮動網卡**：使用者可在指定子網建立獨立的虛擬通訊埠，自訂指定或動態分配私有 IP，並指派安全群組防護。
* **允許地址對 (Allowed Address Pairs)**：
  * **核心價值**：解除虛擬化底層針對 IP/MAC 的防偽冒限制（Anti-Spoofing）。
  * **適用場景**：部署 **Keepalived、VRRP 高可用性虛擬 IP (VIP)**、雙機熱備架構，允許網卡承載非本機主網卡的 IP 流量。
* **QoS 頻寬限速政策**：
  * 支援針對特定浮動網卡配置頻寬上下限，包含最大傳輸速率與突發流量控制（Burst Rate），防止單一主機佔用過多網路頻寬。
* **動態掛載/卸載**：支援熱插拔掛載至運行中的 FiCo 虛擬機作為次要網卡（Secondary NIC）。

---

### 2.5 對等連接 (VPC Peering)

* **跨專案/跨網路互聯**：實現不同 VPC 虛擬網路之間安全、高速的內部私網互通，流量無需經過公網。
* **操作流程**：
  1. **建立連線邀請**：發起端需輸入對端所屬的「目標專案 ID」與「目標網路 ID」，系統產生連線請求。
  2. **審核流程**：對端專案管理者於列表檢視邀請，可選擇「接受邀請」或「拒絕邀請」。
  3. **分離與刪除**：建立互聯後，可隨時「分離連線（Detach）」以暫停流量轉送，或直接刪除對等連接通道。
