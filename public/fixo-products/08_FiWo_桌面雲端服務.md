## 1. 產品定位與桌面雲架構

FiWo（Desktop Cloud Service / VDI）為企業提供高安全性的集中化雲端桌面辦公解決方案。使用者可透過任意終端（筆電、平板、瘦客戶端 Thin Client）透過網頁或遠端協定存取專屬虛擬桌面，實現資料不落地、集中化管理與彈性遠距辦公。

```mermaid

    User([終端辦公使用者 / 瀏覽器]) -->|HTTPS / RDP 協定| RDGW[FiWo RDGW\n遠端桌面閘道 IP (浮動 IP)]
    Admin([IT 管理人員]) -->|管理入口 / 控制台| WebPortal[FiWo Web\n控制台 IP (浮動 IP)]
    
    subgraph FiWo 工作區 Workspace (單一專案限額 1 組)
        WebPortal --- AD[FiWo AD 伺服器\n網域目錄與帳號驗證]
        RDGW --- AD
        RDGW --> UserVM1[使用者桌面虛擬機 A\n(Windows / Linux)]
        RDGW --> UserVM2[使用者桌面虛擬機 B\n(Windows / Linux)]
    end
```

## 2. 工作區規劃與建立規範 (Workspace)

### 2.1 建立前置條件與關鍵配額
建立 FiWo 工作區前，必須事先準備好底層網路資源：
* **VPC 租戶網路**：工作區虛擬機運行的內部專用子網。
* **兩組獨立浮動 IP（關鍵資源準備）**：
  1. **控制台 IP（Console Floating IP）**：供 FiWo Web 管理平台對外存取使用。
  2. **遠端桌面閘道 IP（RDGW Floating IP）**：供終端使用者透過加密通道串流連線至桌面使用。
* **專案配額限制**：**每個 FiXo 專案僅允許建立一個工作區**。

### 2.2 Active Directory (AD) 網域設定
* **系統預設 AD**：由平台自動部署全新的 Windows AD 網域控制器，快速開箱即用。
* **自定義外部 AD**：支援將 FiWo 桌面無縫接入企業既有的自建 Windows Server Active Directory 網域，沿用公司現行員工帳號密碼與 Group Policy（GPO）安全性群組原則。

## 3. 工作區核心資源管理 (Resource Management)

工作區架構內部將虛擬機清晰劃分為兩大類別：

### 3.1 系統核心虛擬機（三大基礎元件）
系統初始化時自動生成三個專屬系統虛擬機，負責支撐整個 VDI 服務運作：
1. **FiWo Web**：提供桌面雲的前端管理門戶，用於配置桌面池、指派使用者與管理鏡像。
2. **FiWo AD**：負責提供網域目錄服務、電腦物件管理與 Kerberos / NTLM 身分認證。
3. **FiWo RDGW（Remote Desktop Gateway）**：安全傳輸代理閘道，將外網 HTTPS 封包轉換並安全代理轉送至內網各使用者桌面。

### 3.2 系統虛擬機專屬維護功能
* **緊急控制台（Web Console）**：在桌面閘道異常、網卡中斷或網路設定失誤導致遠端無法登入時，提供免網路的直連控制台進行緊急排錯。
* **重新開機（Reboot）**：支援在入口直接向特定系統虛擬機發出重新啟動指令，恢復異常服務。

### 3.3 使用者桌面虛擬機 (User Desktop VMs)
* 列表呈現所有已派發給企業員工的虛擬桌面清單。
* 支援依作業系統型態、運行狀態（運行中、關機）、私有 IP 及指派浮動 IP 進行快速篩選與排序。

## 4. 存取入口與使用者體驗

* **工作區入口網站 (FiWo Portal)**：
  * 提供使用者登入遠端桌面的 Web 專屬位址。
  * 介面詳細列出 DNS 解析與**用戶端 Hosts 綁定設定指引**，輔助使用者順利解析網域名稱進入雲端桌面工作環境。
* **工作區刪除**：刪除工作區將連帶清除其下掛載的所有系統虛擬機與使用者桌面，需透過高安全層級之確認流程方可執行。
