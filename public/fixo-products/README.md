# FiXo 雲端平台產品架構與 3D 政策島（Heart Island）全景指南

本資料夾彙整自 **《FiXo User Portal Manual v5.4.1.0 繁體》**（共 305 頁），針對 FiXo 雲端平台之基礎平台規範與各核心雲端產品進行架構分析與重點項目提煉。同時全面整合了 **Heart Island 政策島 3D** 互動體驗，以 **高雄軟體科技園區（高軟 KSP / 鴻海高軟雲端研發中心）** 與 **亞洲新灣區** 為世界觀，打造寓教於樂的雲端架構探索沙盒。
