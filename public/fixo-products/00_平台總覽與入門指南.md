# FiXo 雲端平台入門指南與通用機制

本文件彙整自《FiXo User Portal Manual v5.4.1.0》第 1 章至第 3 章，涵蓋 FiXo 雲端平台的基礎存取、安全防護機制、四大金鑰架構、導覽架構及多區域管理。

---

## 1. 平台存取與帳號機制

### 1.1 多語系支援
* **支援語言**：繁體中文、簡體中文、英文。
* **切換途徑**：
  * **登入前切換**：登入頁面底部的語系下拉選單。
  * **登入後切換**：頂部導覽列右側的「地球」圖示選單。

### 1.2 註冊與登入
* **帳號註冊流程**：
  1. 輸入使用者電子信箱（作為登入帳號及重要通知接收管道）。
  2. 設定符合強度規範的密碼（須包含英文字母大小寫、數字與特殊符號組合）。
  3. 輸入圖形驗證碼並勾選同意平台服務條款。
  4. 提交後系統發送驗證啟用信至註冊信箱，點擊信件連結完成帳號啟用。
* **重置密碼流程**：
  * 於登入頁點選「重置密碼」，輸入已註冊的電子信箱。
  * 系統寄送包含專屬重置連結的電子郵件，引導設定新密碼。

## 2. 安全防護與控制機制

### 2.1 登出與超時閒置防護（節流機制）
為防範無人看管的終端遭受未授權存取，FiXo 具備自動超時登出防護：
* **閒置超時設定**：當使用者在頁面處於無操作狀態達到 **30 分鐘**，系統將自動登出並重新導向至登出頁面。
* **狀態檢查頻率**：系統每隔 **30 秒**主動檢查最後操作時間戳記。
* **操作更新節流（Throttle）**：滑鼠移動、點擊、頁面捲動或鍵盤輸入等事件，透過節流機制每 **30 秒**更新一次操作時間戳記，避免頻繁請求影響瀏覽器效能。

### 2.2 刪除操作防護機制（二次確認）
針對各項雲端資源的刪除作業，平台設計雙層防誤刪機制：
1. **確認提示框（輕量防護）**：適用於一般或低相依性資源，點擊刪除後彈出警告對話框，需再次點擊「刪除」按鈕確認。
2. **強制輸入項目名稱確認視窗（高風險防護）**：適用於虛擬機、叢集、路由器等重大資源。系統列出將一併連帶清除的相依資源，並**要求使用者手動輸入該資源的完整名稱**，比對相符後方可執行刪除。

## 3. FiXo 四大金鑰體系架構

FiXo 平台針對運算主機、物件儲存、加密憑證等不同維度，劃分四種用途的金鑰與金鑰對：

| 金鑰類型 | 核心組成 | 主要應用場景 | 對應服務 |
| :--- | :--- | :--- | :--- |
| **FiCo 金鑰對** | 公鑰（Public Key）+ 私鑰（Private Key） | Linux 虛擬機的 SSH 免密碼連線驗證、Windows 預設密碼解密 | [FiCo 計算機服務](03_FiCo_計算機服務.md) |
| **FiBo 金鑰對** | SecretId + SecretKey | S3 相容物件儲存服務的 API 簽章身分認證與存取權限控管 | [FiBo 物件儲存服務](04_FiBo_物件儲存服務.md) |
| **KMS 非對稱式金鑰** | 公鑰 + 私鑰（預設 RSA 2048 位元） | 資料加密、解密、數位簽章驗證與應用層密碼學運算 | [KMS 金鑰管理服務](07_KMS_金鑰管理服務.md) |
| **KMS 對稱式金鑰** | 單一對稱金鑰（如 AES-256） | 單一密鑰加解密，主要用於 FiBo 物件儲存伺服器端加密 (SSE) | [KMS 金鑰管理服務](07_KMS_金鑰管理服務.md) |

## 4. 平台架構與導覽切換

### 4.1 全域服務 vs. 區域服務
FiXo 將雲端功能明確區分為兩大範疇：
* **全域服務（Global Services）**：
  * 不受單一資料中心/區域限制的全域層級功能。
  * 包含：CAM 帳戶管理、跨域備份、訂單與計費總覽等。
* **區域服務（Regional Services）**：
  * 依資料中心地域部署的運算、網路與資料服務。
  * 包含：FiCo 運算、VPC 網路、FiBo 物件儲存、LBS 負載平衡、CIS 容器、FiWo 桌面雲、BDS 大數據、Meter 計量等。

### 4.2 多區域架構與切換（Regions）
* **入口網（User Portal）**：登入後可透過入口卡片直接進入指派區域（如 `CES-IT`、`TJ-TB-FiXo4`、`TJ-TB-FiXo5`）。
* **頂部區域切換器**：在區域服務視圖下，可透過頂部導覽列隨時切換目標區域。
* **啟用新區域**：若使用者獲授權存取新區域，可於區域卡片點擊「啟用此區域」，系統將自動初始化建立**預設專案**與**預設網路環境**。

### 4.3 帳號選單與專案 ID
* **專案識別（Project ID）**：在區域視圖中，帳號選單顯示當前所屬專案名稱與專案 ID，並附帶「一鍵複製」按鈕，便於維運溝通或 API 調用。
* **切換專案**：若使用者所屬帳號隸屬多個專案群組，可於選單中彈性切換工作專案環境。
