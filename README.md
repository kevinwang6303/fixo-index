# FiXo Cloud Island ☁️ 雲端探索之島

以 **Heart Island (探索之島)** 為概念靈感的互動式產品官網，專為 **Foxconn FiXo 雲端平台** 打造。
訪客可操控虛擬探索員在浮空科技島嶼漫步，透過沈浸式互動探索手冊涵蓋的 10 大雲端核心產品。

---

## 🌟 核心特色

1. **沉浸式地圖漫遊 (Heart Island Style)**
   - 浮空科技島、未來感賽博風格建築群、發光數位道路與動態資料流。
   - 支援 **鍵盤 (WASD / 方向鍵)**、**滑鼠點擊導航** 與 **行動端虛擬搖桿**。
   - 角色步行音效、互動音效與全產品解鎖慶祝彩帶 (Confetti)。

2. **FiXo 手冊 10 大產品矩陣 (Ch 4 ~ Ch 13)**
   - 🏛️ **CAM 認證總督府** (Ch 4 帳戶管理與 MFA 雙因素)
   - 🌐 **VPC 網路立體中樞** (Ch 5 虛擬私有網路、路由器、浮動 IP 與對等連接)
   - ⚡ **FiCo 超算核心主塔** (Ch 6 計算機、虛擬機、映像檔、親和性群組、快照與跨域備份)
   - ⚓ **FiBo 數據深水海港** (Ch 7 S3 相容物件儲存、持久性與生命週期)
   - ⚖️ **LBS 智慧流量燈塔** (Ch 8 進階負載平衡、第七層導流政策與健康檢查)
   - 🐳 **CIS 海神容器船塢** (Ch 9 Kubernetes 託管叢集與海神 Poseidon 平台)
   - 🔐 **KMS 密鑰地下金庫** (Ch 10 硬體金鑰、對稱/非對稱加密與數位憑證)
   - 🖥️ **FiWo 雲端未來工作站** (Ch 11 隨選 VDI 虛擬桌面、資料防洩漏)
   - 📊 **BDS 數據智慧觀測台** (Ch 12 大數據分散式運算叢集、批次排程與分析)
   - 📈 **Meter 綠色計量觀測雷達** (Ch 13 即時費用報表、網路流量分析與操作歷程審計)

3. **商務兼顧的雙軌導覽**
   - **全島雷達 (Minimap)**：即時追蹤探索員座標與已解鎖地標，點擊雷達地標可直接傳送。
   - **快速產品目錄 (Quick Nav)**：提供關鍵字搜尋、類別篩選與一鍵彈窗檢視。
   - **現代 Web 規範**：遵循 W3C 規範之原生 `<dialog>` 模態窗，支援鍵盤無障礙操作、焦點管理與防穿透捲動。

---

## 🚀 快速啟動

```bash
# 1. 安裝相依套件 (如尚未安裝)
npm install

# 2. 啟動開發伺服器
npm run dev

# 3. 建置生產環境版本
npm run build
```

啟動後請以瀏覽器開啟 [http://localhost:3000](http://localhost:3000)。
